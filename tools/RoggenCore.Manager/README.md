# RoggenCore Manager

Native Windows management application for SoluM/Newton M3 nRF52811 displays connected through the ESP32 SWD bridge.

## Safety model

- Discovers new RoggenCore bridges through USB serial and discovers older bridges through `swd.local`, the ESP32 fallback AP, saved addresses, or the local subnet.
- Identifies SWD ID, nRF part, flash geometry, device ID, lock state, UICR board word, and known display profile.
- Saves timestamped full-flash and UICR backups under `%APPDATA%\RoggenCore\backups`.
- Automatically imports existing 192 KiB backups from `D:\NewtonFrame-Backups` when present, and can import any selected folder.
- Records per-device last backup and last-known-good hashes in `%APPDATA%\RoggenCore\firmware-state.json` using atomic replacement.
- Requires Intel HEX checksum, package CRC-32, package SHA-256, target identity, flash size, and allowed address-range validation.
- Erases only manifest-declared pages during normal upgrades.
- Compares all target flash against the expected image before reset. A mismatch leaves the target halted for recovery.
- Recovery erase is separated from normal upgrades and requires an exact device-bound confirmation phrase plus a second warning.

The manager never treats the ESP32 upload response alone as proof of success; readback is authoritative.

## Build and package

Run `scripts/Publish-RoggenCoreManager.ps1`. It runs the tests and produces a self-contained Windows x64 ZIP under `artifacts/`.

Firmware manifests are generated by `scripts/Build-RoggenCoreFirmwarePackage.ps1`. Use `upgrade-manifest.json` for an unlocked RoggenCore target. Use `recovery-manifest.json` only when intentionally removing factory protection and firmware from the verified 648×480 profile.

## Initial display image

E-paper retains its prior image without power, so flashing firmware cannot inherently remove the visible factory/Newton picture. After installing RoggenCore, use RoggenCore Studio's welcome-frame action or upload any converted image. That first verified refresh replaces the retained artwork.
